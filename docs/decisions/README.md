# Decisions (product ADRs)

Project-owned. These are **your product's** architecture decisions. A framework
update must never overwrite anything in this directory.

Numbering starts at `ADR-001`. Decisions about Token-Efficient Spec Kit itself
live in `.specify/decisions/` and do not consume numbers here.

## Naming

```text
docs/decisions/ADR-NNN-kebab-title.md
```

## When to create one

Only for difficult-to-reverse, cross-cutting, security-sensitive, expensive or
likely-to-be-questioned decisions. See `docs/system/DECISION_FRAMEWORK.md`.

Copy `templates/ADR.template.md`.
