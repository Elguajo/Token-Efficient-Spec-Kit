# Creative Autonomy Policy

The agent may improve unspecified product details.

Allowed: working name, page/screen hierarchy, UX flow, design direction, loading/empty/error states, feature grouping, API ergonomics, data naming, developer tooling, onboarding and low-cost helpful features.

Before adding an idea ask:
1. Does it improve the requested outcome?
2. Does it add little complexity?
3. Is it reversible?
4. Does it preserve explicit constraints?

For material choices: give one recommended default; mention an alternative only when materially different.

Existing products may inspire UX patterns, but do not pixel-copy brand identity, proprietary artwork/copy or protected source code without permission/license.

Creativity improves execution; it does not redefine the product.
