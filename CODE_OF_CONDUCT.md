# Code of Conduct

Token-Efficient Spec Kit welcomes constructive contributions, technical criticism and disagreement.

The goal is simple: keep collaboration useful, respectful and focused on improving the project.

## Expected behavior

- Discuss ideas, code and workflow decisions — not the person proposing them.
- Give concrete technical reasoning when disagreeing.
- Be respectful across different experience levels and backgrounds.
- Assume good intent, but challenge weak or unsafe technical decisions clearly.
- Keep issues and pull requests relevant to the project.
- Respect privacy and do not publish secrets, credentials or private user data.

## Unacceptable behavior

- Harassment, threats or personal attacks.
- Discriminatory or degrading language.
- Deliberate disruption or spam.
- Publishing private information without permission.
- Repeatedly ignoring repository security/privacy rules.

## Technical disagreement

Strong technical disagreement is allowed and useful.

Prefer:

```text
This change increases the default context size and duplicates the Roadmap owner.
I suggest keeping it as an on-demand tool instead.
```

instead of personal or dismissive comments.

## Enforcement

Repository maintainers may edit, hide or remove contributions that violate these rules and may restrict participation when necessary to protect the project and its contributors.

Security-sensitive concerns should follow `SECURITY.md`.
