# Roadmap

Create independently verifiable phases appropriate to project complexity.

## Phase status markers

This list is the canonical pointer to the current phase. Exactly one phase may be
marked `[>]`. See `docs/system/TOKEN_EFFICIENCY.md`.

```text
[ ] PLANNED       not started
[>] IN PROGRESS   the current phase - exactly one at a time
[x] COMPLETE      all acceptance criteria verified
```

## Phases

- [>] Phase 00 - Foundation - IN PROGRESS - `docs/phases/00-foundation.md`
- [ ] Phase 01 - ... - PLANNED - `docs/phases/01-....md`

## Completion definition

Primary end-to-end user flow works and acceptance criteria are verified.
When every phase is `[x]`, the project is complete.
